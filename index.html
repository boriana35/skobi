Да си припомним

Съдружително свойство: (a + b) + c = a + (b + c).

Можем да групираме събираемите по различен начин — сборът остава същият. При изваждане тук упражняваме изваждане от сбор.

(20 + 5) + 3 = 20 + (5 + 3) = 28
